# Changelog

All notable changes to the Varbase AI Editor Assistant recipe are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.2] - 2026-10-11
### Changed
- Add the default `.gitlab` and `.github` issue and merge request templates. See [#3614567](https://www.drupal.org/i/3614567).
- Set the recipe version to `1.0.2`.

## [1.0.1] - 2025-07-01
### Changed
- Require `drupal/ai` `~1.1.0`. See [#3532978](https://www.drupal.org/i/3532978).
- Say in `README.md` that the Varbase AI Default recipe must be applied first, and show both ways to apply this recipe: the Drupal recipe script or Drush. See [#3533378](https://www.drupal.org/i/3533378).
- Set the recipe version to `1.0.1`.

## [1.0.0] - 2025-01-26
### Added
- Initial release of the Varbase AI Editor Assistant recipe: installs AI CKEditor and adds the AI Assistant button to a CKEditor 5 text editor, asking for the editor machine name (default `full_html`) and the button position. See [#3502278](https://www.drupal.org/i/3502278).
